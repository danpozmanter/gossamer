# `std::hash::fnv`

Status: experimental

FNV-1a non-cryptographic hash (32-bit, 64-bit).

## Public items

| Name | Kind | Description |
|---|---|---|
| `hash32` | fn | 32-bit FNV-1a of a byte slice. |
| `hash64` | fn | 64-bit FNV-1a of a byte slice. |
| `hash_string` | fn | 64-bit FNV-1a of a String. |
