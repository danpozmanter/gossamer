# Source-Visible Surface Audit Matrix

This matrix tracks surfaces that previously accepted a program and then ignored
work, silently fell back to a weaker behavior, or diverged between the VM,
Cranelift, and LLVM tiers. A row is `Shipped` only when resolve/typecheck,
runtime behavior, and tier evidence agree; otherwise the row stays
`Experimental`, `Planned`, or rejected by the shared frontend.

| Surface | Resolve | Typecheck | VM | JIT | AOT | Platform / Limits | Evidence | Lifecycle |
|---|---|---|---|---|---|---|---|---|
| Scalar indexing `xs[i]`, `xs[i] = v` | Shared expression lowering | `i64` index; element typed | Invalid index panics | Same bounds ABI | Same bounds ABI | Applies to Vec, slice, fixed-array scalar storage | `oob_index_scalar_panic.gos`, `oob_index_aggregate_panic.gos`, `bce_loop_versioning.gos` | Shipped |
| Method Vec `insert` / `remove` | Method dispatch on Vec/slice/array receivers | `insert: 0..=len`; `remove: 0..len` | Invalid index panics | `gos_rt_vec_insert_at`, `gos_rt_vec_remove_at` panic | Same C ABI | Mutates receiver in place | `vec_method_oob_panic.gos`, `vec_method_remove_oob_panic.gos`, `winb2_vec_insert_remove.gos` | Shipped |
| Qualified `Vec::insert` / `Vec::remove` | Qualified stdlib function | Returns `Result` | Returns `Err` on invalid index | `gos_rt_vec_insert_safe`, `gos_rt_vec_remove_safe` | Same C ABI | Explicit non-panicking API | `winb_coll_vec.gos`, `vec_remove_inplace.gos` | Shipped |
