    Source-Visible Surface Audit Matrix¶

    This matrix tracks surfaces that previously accepted a program and then ignored work, silently fell back to a weaker behavior, or diverged between the VM, Cranelift, and LLVM tiers. A row is Shipped only when resolve/typecheck, runtime behavior, and tier evidence agree; otherwise the row stays Experimental, Planned, or rejected by the shared frontend.
