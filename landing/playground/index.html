Try Gossamer

Standalone demo for the embeddable playground component. Each block below is a separate mountPlayground() instance wired to the bundled stub runtime.

Running against runtime-stub.js, so every Run prints a fixed placeholder rather than executing the program. Swap in the real WebAssembly VM by passing runtimeUrl: "./gossamer_playground.js" - no other change.

1. Forward-pipe dataflow

Autoruns on load - verifies mount + lazy runtime load + render.

2. Goroutines and channels

Editable - press Run (or Ctrl/Cmd+Enter), then Reset.

3. Enums and exhaustive match

Exercises types, format specs, and comment highlighting.

Component: playground.js · tokenizer: gossamer-lang.js · styles: playground.css. Open this file over http(s) (an ES-module import and CodeMirror from esm.sh both require it) - a file:// open will not load the editor.
